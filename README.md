# Google-Colab-Notebooks

## GDCA OCR — v1.1.0-GDCA

[![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/tbcreator71/Google-Colab-Notebooks/blob/GDCA_OCR_Notebooks/GDCA_Surya_GPU.ipynb)

فرع مستقل `GDCA_OCR_Notebooks` مبني على `ComfyUI_Notebooks`. الدفاتر الموجودة محفوظة دون تغيير. دفتر OCR يتبع أسلوب Settings → Install → Download → Run → Diagnostics، مع حقول Colab وإصدار واضح.

### التشغيل

1. افتح زر Colab واختر NVIDIA GPU متاحاً من Runtime.
2. شغّل Settings ثم Install ثم Public manifest ثم Models ثم Run.
3. الافتراضي ثلاث صفحات فقط. راجع الزمن والنص قبل توسيع العينة أو تشغيل دفعة من الأرشيف.
4. النتائج والأوزان لها نسخة احتياطية في Drive؛ المعالجة تتم من القرص المحلي السريع داخل جلسة Colab.
5. نزّل ZIP من Export، وافصل جلسة Colab عند الانتهاء؛ إغلاق محرك OCR لا يوقف احتساب جلسة GPU.

### حالة التقدم

التثبيت يعرض مخرجات pip والبناء، ويطبع الوقت المنقضي كل 15 ثانية حتى عند صمت العملية. استمرار العملية ليس ضماناً لتقدمها. المهل: تثبيت 10 دقائق، تنزيل كود المحرك 5 دقائق، تهيئة البناء 5 دقائق، وبناء CUDA 20 دقيقة. تنزيل الملفات يعرض الحجم المنقول، وكل صفحة مكتملة تحفظ مع بصمتها وزمنها. توجد خلية Diagnostics منفصلة.

### نطاق البيانات

الدفتر يحتوي فقط كوداً وفهرساً عاماً لروابط وبصمات 1,522 ملف PDF / 7,072 صفحة من الموقع الحكومي. لا يحتوي أصول PDF أو ملفات قضية أو ملاحظات خاصة. يجلب PDFs عند الحاجة ويتحقق من مطابقتها للقطة المؤرشفة. النتائج غير مراجعة ولا تثبت ملكية أو صحة محتوى الوثائق؛ درجة الثقة ليست دقة مقاسة.

### التحديث

رابط الفرع أعلاه ثابت. بعد تحديث GitHub افتحه مجدداً للحصول على أحدث إصدار؛ التعديلات لا تدخل تلقائياً إلى دفتر مفتوح أو نسخة مستقلة محفوظة في Drive. النسخة الحالية **v1.1.0-GDCA (2026-11-15)**. فُحصت الخلايا محلياً، ولم يُقَس أداء GPU عبر حساب المستخدم أثناء نشر هذا الفرع.
